    Módulo 06 — Git & GitHub para Projetos Reais (Bônus)¶

    Curso: Python para Desktop
    Módulo: 06 · bônus (fora da trilha principal)
    Descrição: Aprenda a versionar seu código, trabalhar em equipe e publicar seu Projeto Final como um profissional usando Git e GitHub.

    📋 Visão Geral do Módulo¶

    Este módulo bônus ensina as ferramentas que todo desenvolvedor profissional usa no dia a dia: Git para controle de versão e GitHub para colaboração e publicação de projetos. Ao final, o repositório do seu Projeto Final estará pronto para ser mostrado a qualquer recrutador.

    Por que este módulo é importante?

    Saber programar é metade do caminho. A outra metade é saber organizar, versionar e apresentar seu trabalho. Nenhuma empresa contrata um desenvolvedor que não sabe usar Git. Este módulo garante que você saia do curso com essa habilidade essencial.

    📚 Capítulos¶

    • 01. Criando um Projeto Profissional
    • 02. Publicando o Projeto Final

    🎯 Objetivos do Módulo¶

    Ao final deste módulo, você será capaz de:

    • Entender o que é Git e GitHub e por que são essenciais
    • Criar e configurar um repositório profissional (README, .gitignore, LICENSE)
    • Usar Git via GitHub Desktop e Terminal (5 comandos essenciais)
    • Trabalhar em equipe com commits, push e pull
    • Resolver conflitos básicos de merge
    • Escrever commits profissionais com mensagens claras
    • Criar um README completo com badges e screenshots
    • Publicar releases versionadas (v1.0.0)
    • Usar IA para gerar documentação de qualidade
    • Preparar seu repositório como portfólio profissional

    Organização

    Este é um módulo bônus que complementa o curso principal. Ele pode ser feito a qualquer momento após o Módulo 03, mas é mais proveitoso durante ou após o Projeto Finalizador (Módulo 05).

    🧭 Antes de começar¶

    • Pré-requisitos: Ter um projeto para versionar — idealmente o do Módulo 05.
    • Tempo estimado: ~5 h (leitura, exemplos e exercícios — estimativa; ajuste ao ritmo da turma)
    • Ao final você terá: o repositório do projeto no GitHub, com README, release e perfil de portfólio.

    ✅ Checklist do módulo¶

    Antes de seguir, confira se você consegue:

    • Crio um repositório com README, .gitignore e licença.
    • Faço add, commit, push e pull sem medo.
    • Resolvo um conflito simples de merge com a equipe.
    • O README tem descrição, prints, instruções e badges.
    • Publiquei uma release v1.0.0 e fixei o projeto no perfil.
