# Módulo 02 — Tarefas úteis

> **Curso:** IA na prática com Python  
> **Módulo:** 02 · Tarefas úteis  
> **Descrição:** Classificar mensagens, extrair dados em JSON, reescrever com tom definido e decidir quando usar regras e quando usar IA.

---

## 📋 Visão Geral do Módulo

Com a API funcionando (Módulo 01), é hora das tarefas que mais ajudam no dia a dia de um pequeno negócio. Você vai **classificar** mensagens de clientes em categorias fixas, **extrair** os dados dos pedidos em **JSON** com um esquema e validação, **reescrever** respostas no tom certo sem deixar a IA inventar promessas e entender **quando não usar IA**, juntando regras e IA num classificador **híbrido**. No projeto, a **triagem de mensagens** tira os dados pessoais, classifica, extrai os pedidos e monta uma planilha com uma aba do que precisa de revisão.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Classificar textos em categorias fixas, validando a resposta.
- Pedir JSON com esquema (`response_format`) e validar o conteúdo.
- Reescrever textos com tom definido, conferindo que nada foi inventado.
- Escolher entre código, IA e pessoa para cada tarefa, e combinar regras com IA.
- Tirar dados pessoais antes de mandar textos para a API.
