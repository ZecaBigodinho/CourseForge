## Sobre este curso

**React é a biblioteca de interfaces mais usada do mercado.** Em vez de mexer no DOM passo a passo, como no curso de Web, você **descreve** como a tela deve ficar para cada situação, e o React atualiza a página sozinho quando os dados mudam. A tela é dividida em **componentes**, peças reaproveitáveis como botões, cartões e listas.

O curso usa React com **TypeScript**, como na maioria das empresas, e o **Vite** para criar e rodar os projetos.

!!! info "Antes deste curso"
    Faça os cursos de **[Desenvolvimento Web](../../desenvolvimento_web/docs/index.md)** e **[TypeScript](../../typescript/docs/index.md)** (pelo menos os Módulos 01 e 02). Este curso usa arrays, objetos, `map`, `filter` e tipos o tempo todo.
