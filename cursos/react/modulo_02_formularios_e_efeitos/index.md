# Módulo 02 — Listas, formulários e efeitos

> **Curso:** React  
> **Módulo:** 02 · Listas, formulários e efeitos  
> **Descrição:** Formulários que o React controla, listas que se filtram e se editam, e efeitos para guardar dados e buscá-los na internet.

---

## 📋 Visão Geral do Módulo

No Módulo 01, o estado vinha de cliques. Agora ele vem de **formulários**, ganha **listas** que se filtram e se editam e passa a conversar com o mundo de fora com **`useEffect`**: guardando no `localStorage` e buscando dados de APIs, com aviso de carregamento e de erro. No projeto, a **lista de tarefas** do curso de Web ganha a sua versão em React.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Criar **formulários controlados** (o React guarda o valor de cada campo).
- Filtrar, editar e remover itens de listas no estado, com `key` estável.
- Usar **`useEffect`** para sincronizar com o `localStorage` e entender o array de dependências.
- Buscar dados de uma API com estados de **carregando**, **erro** e **sucesso**.
