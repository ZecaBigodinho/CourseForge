# Módulo 01 — Fundamentos

> **Curso:** React  
> **Módulo:** 01 · Fundamentos  
> **Descrição:** O primeiro projeto com Vite, JSX, componentes, props e estado: as quatro ideias que sustentam todo app em React.

---

## 📋 Visão Geral do Módulo

Você vai criar um projeto React com Vite, entender a estrutura de pastas e escrever os primeiros **componentes**. Depois passa dados para eles com **props** e faz a tela reagir a cliques com **estado**. No projeto, monta um **cardápio** em que o cliente escolhe as quantidades e vê o total do pedido mudar na hora.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Criar e rodar um projeto com `npm create vite` (modelo React + TypeScript).
- Escrever **JSX** e dividir a tela em **componentes**.
- Passar dados com **props** tipadas e renderizar listas com `map` e `key`.
- Guardar e mudar dados com **`useState`** e responder a eventos.

- **Pré-requisitos:** [Desenvolvimento Web](../../desenvolvimento_web/docs/index.md) e [TypeScript](../../typescript/docs/index.md) (Módulos 01 e 02); Node.js instalado.
