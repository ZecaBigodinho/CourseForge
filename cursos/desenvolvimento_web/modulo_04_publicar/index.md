# Módulo 04 — Publicar

> **Curso:** Desenvolvimento Web  
> **Módulo:** 04 · Publicar  
> **Descrição:** Buscar dados na internet com `fetch`, organizar o projeto como um profissional e publicar o seu portfólio com endereço próprio.

---

## 📋 Visão Geral do Módulo

Até aqui, seus projetos rodavam só no seu computador. Neste módulo a página passa a **buscar dados** de outros sites (APIs), o projeto ganha uma **organização** de pastas que qualquer desenvolvedor entende, e tudo vai para a internet de graça com o **GitHub Pages**. No projeto final, o seu **portfólio** reúne os trabalhos do curso.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Buscar dados de uma **API** com `fetch`, `async` e `await` e mostrá-los na página.
- Tratar **erros** de rede e mostrar um aviso de “carregando”.
- Organizar o projeto em pastas, com nomes de arquivo profissionais e um `README.md`.
- Publicar um site no **GitHub Pages** e atualizá-lo.

## 🧭 Antes de começar

- **Pré-requisitos:** Módulos [01](../modulo_01_html/index.md), [02](../modulo_02_css/index.md) e [03](../modulo_03_javascript/index.md).
- **Conta no GitHub:** gratuita. O curso de [Python para Desktop](../../python_para_desktop/modulo_05_git_github/index.md) tem um módulo completo de Git e GitHub, se quiser aprofundar.
- **Tempo estimado:** ~8 h (estimativa, ajuste ao ritmo da turma)
- **Ao final você terá:** o seu portfólio publicado, com endereço `https://seu-usuario.github.io`.
