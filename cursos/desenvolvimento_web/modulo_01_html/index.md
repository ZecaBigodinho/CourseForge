# Módulo 01 — HTML

> **Curso:** Desenvolvimento Web  
> **Módulo:** 01 · HTML  
> **Descrição:** A estrutura de toda página da web: textos, links, imagens, listas, tabelas e formulários, escritos de um jeito que qualquer pessoa (e qualquer leitor de tela) entende.

---

## 📋 Visão Geral do Módulo

HTML não é difícil: são **etiquetas** (as *tags*) que dizem ao navegador o que é cada parte da página. Neste módulo você cria arquivos `.html` no VS Code, abre no navegador e vê o resultado na hora. No fim, monta a sua **página de apresentação**, que vai ganhar estilo no Módulo 02.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Montar a **estrutura básica** de uma página (`<!DOCTYPE html>`, `<head>`, `<body>`).
- Usar títulos, parágrafos, ênfase, **links** e **imagens** com texto alternativo.
- Organizar informações em **listas** e **tabelas**.
- Criar **formulários** acessíveis, com rótulos e validação do navegador.
- Usar as tags **semânticas** (`<header>`, `<main>`, `<section>`, `<footer>`).

---

## 🧭 Antes de começar

- **Pré-requisitos:** usar o computador, criar pastas e abrir um navegador.
- **Tempo estimado:** ~8 h (leitura, prática e projeto; estimativa, ajuste ao ritmo da turma)
- **Ao final você terá:** uma página `index.html` com a sua apresentação, seus interesses, uma tabela e um formulário de contato.

## ✅ Checklist do módulo

Antes de seguir, confira se você consegue:

- [ ] Criar um arquivo `.html` no VS Code e abri-lo no navegador.
- [ ] Explicar a diferença entre `<head>` e `<body>`.
- [ ] Pôr um link que abre outro site e uma imagem com `alt`.
- [ ] Fazer uma lista numerada e uma tabela com cabeçalho.
- [ ] Criar um formulário com `<label>` ligado a cada campo.
- [ ] Validar a página no validador do W3C sem erros.
