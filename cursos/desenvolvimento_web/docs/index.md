## Sobre este curso

**Todo site é feito de três linguagens:** **HTML** diz *o que* tem na página (títulos, textos, imagens), **CSS** diz *como* ela aparece (cores, fontes, posições) e **JavaScript** diz *o que ela faz* (responder a cliques, guardar dados). Neste curso você aprende as três, uma de cada vez, e fecha cada módulo com um projeto. No fim, o seu **portfólio** estará publicado na internet, com endereço para mandar a quem quiser.

Este curso é a base para os próximos da trilha: **TypeScript** e **React**.

## Ementa

### Módulo 01 — HTML ✅ disponível

Estrutura de uma página, textos, links, imagens, listas, tabelas e formulários, com acessibilidade desde o começo. Projeto: sua **página de apresentação**. [Acessar o módulo](../modulo_01_html/index.md)

### Módulo 02 — CSS ✅ disponível

Seletores, cores e fontes, modelo de caixa, Flexbox, Grid e layout responsivo. Projeto: o **cardápio** de uma lanchonete. [Acessar o módulo](../modulo_02_css/index.md)

### Módulo 03 — JavaScript ✅ disponível

Variáveis, condições, laços, funções, DOM, eventos e `localStorage`. Projeto: uma **lista de tarefas** que lembra o que você digitou. [Acessar o módulo](../modulo_03_javascript/index.md)

### Módulo 04 — Publicar ✅ disponível

Buscar dados de APIs com `fetch`, organizar o projeto e publicar no **GitHub Pages**. Projeto: o seu **portfólio no ar**. [Acessar o módulo](../modulo_04_publicar/index.md)
