# Módulo 03 — JavaScript

> **Curso:** Desenvolvimento Web  
> **Módulo:** 03 · JavaScript  
> **Descrição:** A linguagem que dá vida às páginas: guardar valores, tomar decisões, repetir tarefas e reagir aos cliques do visitante.

---

## 📋 Visão Geral do Módulo

HTML é o conteúdo e CSS é a aparência. **JavaScript** é o comportamento: ele faz contas, decide, repete e muda a página enquanto ela está aberta. Neste módulo você aprende a lógica da linguagem, aprende a mexer no HTML pelo código (o **DOM**) e fecha com uma **lista de tarefas** que lembra o que foi digitado mesmo depois de fechar o navegador.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Usar **variáveis** (`let`, `const`), **tipos**, **condições** e **laços**.
- Escrever **funções** e trabalhar com **arrays** e **objetos**.
- Encontrar e alterar elementos da página pelo **DOM**.
- Reagir a **eventos** (clique, envio de formulário, digitação).
- Guardar dados no navegador com **`localStorage`**.

## ✅ Checklist do módulo

Antes de seguir, confira se você consegue:

- [ ] Abrir o **Console** do navegador e usar `console.log`.
- [ ] Escolher entre `let` e `const`.
- [ ] Escrever um `if`/`else` e um laço `for…of`.
- [ ] Criar uma função que recebe valores e devolve um resultado.
- [ ] Mudar o texto de um elemento com `querySelector` e `textContent`.
- [ ] Responder ao clique de um botão com `addEventListener`.
