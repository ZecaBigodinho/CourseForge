# Módulo 02 — CSS

> **Curso:** Desenvolvimento Web  
> **Módulo:** 02 · CSS  
> **Descrição:** Cores, fontes, espaços e layout: como transformar o HTML cru numa página bonita que funciona no computador e no celular.

---

## 📋 Visão Geral do Módulo

No Módulo 01 a página tinha conteúdo, mas aparência de documento antigo. O **CSS** cuida da aparência: cores, fontes, espaçamentos e a posição de cada bloco. Você aprende a escrever regras, a entender o **modelo de caixa** e a montar layouts com **Flexbox** e **Grid**, que se adaptam ao celular. No projeto, monta o **cardápio** de uma lanchonete inventada.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Ligar um arquivo **CSS** ao HTML e escrever regras com **seletores**.
- Usar **cores**, **fontes** e **unidades** (`px`, `rem`, `%`).
- Controlar **margem**, **borda**, **preenchimento** e tamanho (modelo de caixa).
- Alinhar e distribuir elementos com **Flexbox** e montar grades com **Grid**.
- Adaptar a página ao celular com **media queries**.

## ✅ Checklist do módulo

Antes de seguir, confira se você consegue:

- [ ] Ligar um `style.css` ao HTML com `<link>`.
- [ ] Escolher um elemento por tag, classe e `id`.
- [ ] Explicar a diferença entre `margin` e `padding`.
- [ ] Pôr um menu na horizontal com Flexbox.
- [ ] Montar uma grade de cartões com Grid.
- [ ] Fazer a página mudar de layout no celular com `@media`.
