## Sobre este curso

**TypeScript é JavaScript com tipos.** Você diz que `preco` é um número e `nome` é um texto, e o editor avisa **antes de rodar** quando algo não bate: um nome de propriedade digitado errado, um texto onde devia ir um número, uma função chamada com valores faltando. No fim, o TypeScript vira JavaScript comum, que roda em qualquer navegador.

Por isso ele é usado na maioria dos projetos profissionais de front-end e é a base do próximo curso da trilha, **React**.

!!! info "Antes deste curso"
    Você precisa do JavaScript do curso de **[Desenvolvimento Web](../../desenvolvimento_web/docs/index.md)** (Módulo 03): variáveis, funções, arrays, objetos e DOM.
