# Módulo 02 — Orientação a objetos

> **Curso:** Java  
> **Módulo:** 02 · Orientação a objetos  
> **Descrição:** O jeito Java de organizar programas: classes que juntam dados e comportamento, protegidas por encapsulamento e reaproveitadas com herança e interfaces.

---

## 📋 Visão Geral do Módulo

No Módulo 01, tudo ficava no `main`. Programas reais têm **alunos**, **produtos**, **pedidos**: coisas com dados e regras próprias. A **orientação a objetos** (OO) organiza o código em **classes** que representam essas coisas. Você vai criar classes e objetos, protegê-los com **encapsulamento**, reaproveitar código com **herança** e **interfaces** e usar `enum` e `record`. No projeto, monta um **cadastro de alunos** com menu.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Criar **classes** com atributos e métodos e **instanciar** objetos com `new`.
- Proteger os dados com `private`, **construtores**, *getters* e validação.
- Usar **herança** (`extends`), sobrescrita (`@Override`) e **polimorfismo**.
- Definir contratos com **interfaces** e usar `enum` e `record`.
