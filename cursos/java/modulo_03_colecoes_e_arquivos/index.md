# Módulo 03 — Coleções, exceções e arquivos

> **Curso:** Java  
> **Módulo:** 03 · Coleções, exceções e arquivos  
> **Descrição:** Guardar muitos dados, processá-los com streams, tratar os erros com elegância e salvar tudo em arquivo: o que falta para um sistema de verdade.

---

## 📋 Visão Geral do Módulo

O cadastro do Módulo 02 esquecia tudo ao fechar. Neste módulo você aprende as **coleções** (`ArrayList`, `HashMap`), os **streams** para filtrar e resumir dados, as **exceções** para tratar erros sem derrubar o programa e a leitura e escrita de **arquivos** com `java.nio`. No projeto final, o cadastro de alunos passa a **salvar e carregar** de um arquivo CSV, que abre até no Excel.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Usar `List`/`ArrayList` e `Map`/`HashMap` com *generics* (`List<Aluno>`).
- Filtrar, transformar, ordenar e resumir coleções com **streams**.
- Lançar, capturar e criar **exceções**, diferenciando as verificadas das não verificadas.
- Ler e escrever arquivos de texto com `Files` e `Path`, em UTF-8.
