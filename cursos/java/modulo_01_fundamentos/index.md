# Módulo 01 — Fundamentos

> **Curso:** Java  
> **Módulo:** 01 · Fundamentos  
> **Descrição:** Do JDK instalado ao primeiro programa que conversa com o usuário: variáveis, tipos, decisões, repetições e métodos.

---

## 📋 Visão Geral do Módulo

Você vai instalar o JDK, escrever e rodar o primeiro programa e entender por que todo código Java mora dentro de uma **classe**. Depois aprende a guardar valores, tomar decisões, repetir tarefas, dividir o código em **métodos** e ler o que o usuário digita. No projeto, monta uma **calculadora de médias** que roda no terminal.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Instalar o JDK e rodar programas com `java` e `javac`.
- Usar os tipos `int`, `double`, `boolean`, `char` e `String`.
- Escrever `if`/`else`, `switch`, `for` e `while`.
- Criar métodos com parâmetros e retorno.
- Ler dados do teclado com `Scanner`, entendendo a vírgula decimal do Brasil.

---

## 🧭 Antes de começar

- **Pré-requisitos:** usar o computador, pastas e o terminal.
- **Tempo estimado:** ~7 h (estimativa, ajuste ao ritmo da turma)
- **Ao final você terá:** um programa de terminal que lê as notas de uma turma e mostra médias e situação.

## ✅ Checklist do módulo

- [ ] Rodar `java -version` e ver a versão 21.
- [ ] Explicar o papel de `public static void main(String[] args)`.
- [ ] Escolher entre `int` e `double` e converter entre eles.
- [ ] Escrever um laço `for` e um `while`.
- [ ] Ler um número do teclado com `Scanner` sem erro de vírgula e ponto.
