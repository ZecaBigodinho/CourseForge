# Módulo 02 — Programação Orientada a Objetos (POO)

> **Curso:** python_para_desktop  
> **Módulo:** 02 · trilha principal (00 a 05)  
> **Descrição:** Estudo aprofundado do Paradigma de Programação Orientada a Objetos (POO) em Python, abrangendo classes, objetos, atributos, métodos de instância, encapsulamento, propriedades (`@property`) e desenvolvimento prático de aplicações desktop.

---

## 📋 Visão Geral do Módulo

A Programação Orientada a Objetos (POO) é um dos paradigmas mais importantes no desenvolvimento moderno de software e a espinha dorsal de frameworks para interfaces gráficas (como Tkinter e CustomTkinter). Neste módulo, você aprenderá a estruturar programas reais modelando entidades do mundo real em classes e objetos flexíveis, reutilizáveis e seguros.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Compreender a diferença entre Programação Procedural e Orientada a Objetos.
- Criar e instanciar **Classes** e **Objetos** em Python.
- Trabalhar com o construtor `__init__`, o parâmetro `self` e métodos de instância.
- Aplicar **encapsulamento** com atributos privados e protegidos.
- Criar getters e setters modernos usando os decoradores `@property` e `@property.setter`.
- Desenvolver uma aplicação desktop completa e modular estruturada em POO.
