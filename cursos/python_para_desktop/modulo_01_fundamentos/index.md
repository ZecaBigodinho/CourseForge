Este módulo apresenta os conceitos fundamentais para o desenvolvimento em Python. Você passará por toda a base da linguagem até ser capaz de construir um sistema completo via linha de comando.

## 🎯 Objetivos do Módulo

Ao final deste módulo, você será capaz de:

- Dominar a sintaxe e as estruturas de controle do Python.
- Criar e utilizar funções, módulos e estruturas de dados (coleções).
- Manipular arquivos, processar textos (strings) e tratar erros de execução robustamente.
- Desenvolver um sistema CLI (Command Line Interface) funcional como Mini-projeto do módulo.

## ✅ Checklist do módulo

Antes de seguir, confira se você consegue:

- [ ] Uso variáveis, tipos e operadores sem consultar a aula.
- [ ] Escrevo decisões (`if/elif/else`) e laços (`for`/`while`) com segurança.
- [ ] Crio funções com parâmetros e `return`, e organizo o código em módulos.
- [ ] Escolho entre lista, tupla e dicionário conforme o problema.
- [ ] Leio e gravo arquivos de texto e JSON.
- [ ] Trato erros com `try/except` para o programa não fechar sozinho.
- [ ] Entreguei o Mini-projeto funcionando.
